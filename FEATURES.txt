================================================================================
  CRYSTALLIZED NEXUS — Custom Features vs. OpenRA Tiberian Sun Mod
================================================================================


RENDERING & VOXELS
------------------
  VoxelDynamics
    Spring-based physics tilts: impact tilt, acceleration tilt, firing recoil,
    roll on turns. All CN voxel units have real-time pitch/roll animation.
    Toggleable via the Graphics settings "Voxel Dynamics" checkbox (see
    ENGINE PATCHES: Custom Graphics Settings Toggles).

  CNWithVoxelBody / Turret / Barrel / WalkerBody / UnloadBody
    Drop-in replacements for all voxel render traits, integrating VoxelDynamics.

  AlphaGradientPalette
    Runtime gradient palette for additive effects.

  CharredPalette
    Charred palette for destroyed units.

  DamageSmoke
    Smoke effects based on damage state.

  PeriodicSpriteEffect
    Periodic sprite effects (e.g. idle animations).

  AtmosphericGradingRenderer
    Full-screen post-process color grading, selectable Off / Cinematic /
    Tox Haze (Graphics settings "Atmosphere" dropdown). Cinematic applies a
    contrast/saturation/vignette/tint/grain/haze grade; Tox Haze is a
    separate preset grade. Backed by Graphics.PostProcessGrading
    (GradingMode enum) — see ENGINE PATCHES: Custom Graphics Settings Toggles.

  BloomGlowEffect
    Sole writer of WorldTintState's bloom state: additive halo on
    full-bright palette-index ranges, gated by a world trait condition.
    Toggleable via the Graphics settings "Bloom Glow" checkbox.

  Water Effects  (WaterSurfaceMask / WaterOverlayRenderer /
                  WaterReflectionRenderer / WaterSparkleRenderer /
                  WithWaterReflection)
    WaterSurfaceMask is a shared palette-index-based water detection layer
    used by the other three world-level post-process passes: a
    weather-reactive color overlay, a lightweight screenspace reflection,
    and dissolving sparkles on lit water. WithWaterReflection clones an
    individual actor's renderable as a reflection when it's above water.
    All gated together by the Graphics settings "Water Effects" checkbox.

  TiberiumGlowRenderer
    Full-screen screenspace glow / fog / particles over Tiberium fields
    (green/blue/red resource groups plus the organic vein effect),
    gated by a resource-layer coverage texture. Toggleable via the
    Graphics settings "Tiberium Effects" checkbox. Distinct from
    ResourceAnimationOverlay (see TERRAIN & MAP), which is the per-tile
    sparkle/poison animation, not the fullscreen glow pass.

  VoxelShadowSmoothing
    Smooths the ground height/orientation used by projected voxel shadows
    for hovering/flying units, reusing the same forward/behind sampling
    pattern as Aircraft.TerrainAltitudeSmoothing (see ENGINE PATCHES:
    Aircraft Terrain Altitude Smoothing) — falls back to it as the default
    Range for aircraft. UseTerrainOrientation: false converges the shadow
    to flat instead of tracking discrete ramp orientation. Requires the
    paired engine patch (see ENGINE PATCHES: Voxel Shadow
    Ground-Orientation Hook) — without it, ShadowGroundOrientation is
    computed but never consumed by the renderer.


WEATHER & ATMOSPHERE
--------------------
  WeatherController
    Full ion storm system: Clear / Warning / Storm / Clearing lifecycle,
    grants `ionstorm` condition to all actors, plays storm music.

  WeatherTintEffect
    Lerps color tint post-processing based on storm intensity.

  IonStormDamage
    Random lightning strikes via weapon warheads during storms.

  AnnounceOnCondition
    Faction-specific voice lines + text notifications on condition changes
    (used for ion storm warnings).

  CloudSpawner / Cloud
    Cloud shadows & godray sprites, pre-spawned across the map.

  CloudShadowRenderer / WorldCloudShadow
    Procedural cloud shadow post-process pass over the terrain
    (CloudShadowRenderer), plus a drifting cloud shadow folded into the
    combined world-tint shader (WorldCloudShadow). Toggleable via the
    Graphics settings "Cloud Shadows" checkbox (see ENGINE PATCHES: Custom
    Graphics Settings Toggles). Distinct from CloudSpawner/Cloud above,
    which are the actual sprite-based cloud/godray actors.


TERRAIN & MAP
-------------
  TerrainAnimationOverlay
    Terrain effects (water waves, etc.).

  ResourceAnimationOverlay
    Tiberium sparkle / poison effects on resource tiles.

  PlacesPavement
    Automatically lays pavement tiles under structures.

  RandomMapAmbientSound
    Random ambient sounds per map.

  TerrainDeformationWarhead
    Terrain deformation via weapons.

  Destroyable Cliffs  [CNDestroyableCliff, CNDestroyableCliffLayer]
    The Tiberian Sun "Destroyable Cliffs" tile set (dcliff01/dcliff02 —
    717/718 temperate+desert, 987/988 snow) made functional. TS shipped no
    destroyed artwork, so the collapsed state is assembled from stock ramp
    templates: 403+404 for the wide cliff, 406+405 for the tall one, which
    retile the footprint exactly and leave a two-cell-wide slope. Configured
    in rules/cliffs.yaml (DestroyedTemplates: template id per cell offset) —
    changing how a collapse looks is YAML, not code.
    CNDestroyableCliffLayer finds the templates on map load and places the
    actors itself, so any existing map using those tiles gets working cliffs;
    fragments below MinimumTemplateCoverage stay decoration. The collapse
    writes Map.Tiles and Map.Height (separate layers in OpenRA, unlike the
    tile set), then recomputes CliffBackImpassability over the area — that
    layer runs once at load and would otherwise keep the new path blocked.
    Bots blow them open via CNCliffDemolitionBotModule (see AI — BOT MODULES).

  ExplodeResourceWarhead
    Chain reactions on resource tiles (blue / red tiberium explodes when hit).


GAMEPLAY MECHANICS
------------------
  HeightAdvantageBonus
    High ground advantage: weapon range and sight range scale with terrain height
    (IRangeModifier + IRevealsShroudModifier). BaseHeight 2 matches RMG maps.
    CNTacticalMapBotModule's high-ground cliff-edge detection
    (HighGroundBaseHeight, see AI — BOT MODULES) is deliberately kept in
    sync with BaseHeight so the AI places defense turrets where they
    actually gain this bonus.

  Slope Speed System  [engine patch]
    Units slow down going uphill and speed up going downhill. Configurable per
    locomotor type. Smooth lerp transition (no instant speed jumps). Ramp
    lookahead detects the first ramp cell even when its height equals flat
    ground so the effect triggers at the visual ramp start.

  Explosive Tiberium
    Blue and red tiberium chain-react when hit by weapons or unit explosions.
    Chain propagates via ExplodeResourceWarhead; resources are cleared to
    prevent infinite loops.

  Scatterer
    Units automatically dodge sideways when a crusher approaches.

  FormationMove
    Rectangular grid formation for multi-unit move orders.

  FadeOut
    Alpha fade over time then dispose (used for corpses and decals).

  RandomTransformsNearResources
    Units randomly transform when near resource fields.

  ExploresMapOnOwnerChange
    Reveals fog of war in actor vicinity when ownership changes.


MOB / SQUAD SYSTEM
------------------
  MobSpawnerMaster / MobSpawnerSlave
    C&C Generals-style aggregate HP: damage is redirected from the master to
    slaves. Supports invisible nexus or visible squad leader mode.

  BaseSpawnerMaster / BaseSpawnerSlave
    Base spawner framework shared by mob and other spawner systems.


UNIT MECHANICS
--------------
  CNHealth
    Custom HP system.

  SecondaryHealth
    Secondary health bar (e.g. for shields or armor layers).

  HuskFacing
    Corrects husk facing when a unit dies mid-turn.

  CNSteeredMobile
    Steered movement for vehicles (smooth arc turns).

  CNAircraftFallsToEarth
    Custom crash behavior for aircraft.

  CallProtectorsOnDamage
    Signals nearby protector units to respond when this actor takes damage.

  SpawnActorOnDamage / SpawnActorOnTimer
    Spawns actors when damage threshold is crossed or on a timer.

  KeepNearActors
    Keeps units within range of specified other actors.

  CNHarvester
    Custom harvester logic with dedicated resource assignment and routing.

  CNHandicapFirepowerMultiplier / CNHandicapDamageMultiplier /
  CNHandicapProductionTimeMultiplier / CNHandicapIncomeMultiplier
    Per-actor handicap traits keyed by named difficulty tier (Easy/Normal/
    Hard/Brutal) rather than the vanilla continuous 0-95% Handicap formula.
    Each reads a Modifiers dict from ^PlayerHandicaps (handicap.yaml) and
    looks up the owner's tier via CNHandicapTiers.Name(Owner.Handicap).
    Requires the paired engine patch (see ENGINE PATCHES: Named Handicap
    Tiers) so the lobby assigns a tier index instead of a percentage.


UI & PLAYER
-----------
  CNProductionPaletteWidget / Tabs / Queue / Selection
    Fully reworked production UI.

  SubgroupIcon / SubgroupButton / SubgroupIconWidget / SelectionSubgroupLogic
    Sub-group system within unit selection (group by type within a selection).

  PlayerDefeatedAnnouncer
    Announces when a player is defeated.

  Defeated Player Strikethrough
    Player-list name gets a strikethrough once WinState == Lost
    (GameInfoStatsLogic sets LabelWidget.IsStrikethroughVisible). Requires
    the paired engine patch (see ENGINE PATCHES: Label Strikethrough) —
    the Strikethrough rendering support doesn't exist in vanilla LabelWidget.

  BotPlayerNames
    Deterministic, faction-specific display names for bots (stable per
    lobby seed, with optional bot-type labels). Requires the paired engine
    patch (see ENGINE PATCHES: Player Name Resolver Hook) — the
    IResolvePlayerName hook it implements doesn't exist in vanilla OpenRA.


AUDIO
-----
  CNDynamicMusicController
    Layered adaptive soundtrack: Peace / Tension / Combat / BigBattle stems,
    crossfaded live based on combat state. Faction-Side-keyed stem sets,
    RenderPlayer-aware so observers/spectators hear the right side's music.
    Tension scored via a decaying weighted scan (FindActorsInCircle) rather
    than polling every actor; per-tick volume lerp exempted from the normal
    volume-slider sweep (Game.Sound.ExemptFromVolumeSlider).

  CNCombatSignalReporter
    Feeds attack/damage events into CNDynamicMusicController. Per-actor
    cooldowns (RecordInterval) and configurable AttackWeight /
    DamageWeightPerPoint so the tension score reacts to real engagements
    without being spammed by every single hit.


AI — BOT MODULES
----------------
  Strategy & Profiles
  ~~~~~~~~~~~~~~~~~~~
    CNBotProfileBotModule
      BotProfile enum (Rush / Turtle / Tech / Expansion / Steamroller /
      Adaptive) driving per-profile budgets and tech-stage gating
      (UpdateTechStage). Emergency Turtle bypass kicks in under genuine
      active threat regardless of the assigned profile. TechBudgetDifficultyScale
      / TechTickDifficultyScale scale tech-pacing by named handicap tier
      (Easy/Normal/Hard/Brutal), not just the raw stat multipliers from the
      CNHandicap* traits — so difficulty affects how fast a bot climbs the
      tech tree, not only how hard its units hit.

    BotCapabilities
      Capability-tag system (Tech, Defense, Economy, Production, Power,
      Superweapon, Vehicle, Transporter, AntiAir, ...) declared per actor.
      Used pervasively across the AI: defense-role classification, squad
      priority-target matching, MCV expansion scoring, wave drop targeting.

  Base & Economy
  ~~~~~~~~~~~~~~
    CNBaseBuilderBotModule
      Base construction with layout strategies (Random / Grid / Clustered /
      Compact / Coverage / BaseGrid), configurable building fractions,
      delays, and per-DefenseRole limits scaled to base size (replaces hard
      defense caps). Wall/gate placement covers both a base perimeter and
      chokepoint sealing (via CNTacticalMapBotModule's sealable corridors).
      Defense placement is fed by tactical-map hotspots and threat-scored
      (ScoreDefensePlacement / ScoreTechPlacementSafety), picking reactively
      by CombatAnalysisBotModule's live threat role or falling back to a
      planned per-role deficit.

    CNBaseBuilderQueueManager
      The per-tick build-queue decision engine backing CNBaseBuilderBotModule:
      power priority, refinery placement (pre-flight reachable-field +
      cluster-saturation checks so a doomed refinery never jams the queue),
      naval production gating, silo pressure, wall/gate/chokepoint search,
      building-fraction deficit scoring, DefenseRole-aware reactive/planned
      defense selection.

    CNUnitBuilderBotModule
      Unit production and army composition. Panic-mode: when a bot has no
      real defense force and is under active threat, bootstraps missing
      cheap production buildings and spams cheap infantry/vehicle defenders
      — scoped tightly to genuine emergencies (HasNoRealDefenseForce) so it
      never becomes a general production boost for a bot that already has
      an army.

    CNHarvesterBotModule
      Harvester resource-field assignment/routing, with stuck-detection
      near refineries so a harvester with a full load doesn't permanently
      jam waiting for the dock while empty harvesters queue up behind it.

    CNResourceMapBotModule
      Divides the map into a grid of indices tracking resource density,
      own refinery/harvester counts, and nearby enemy/friendly presence per
      cell. Feeds MCV expansion scoring and harvester safety checks —
      GetNearbyIndicesThreat aggregates the 3x3 neighborhood around an
      index, bounded per-axis so edge-of-map indices don't wrap into the
      wrong row.

    CNMcvExpansionManagerBotModule
      MCV deploy/expansion decisions in two modes: CheckResource (economy
      expansion, weighted toward rich-but-not-flooded resource fields) and
      CheckBase (forward outposts, with a frontline-corridor bonus toward
      the enemy). Routes MCVs around known enemy bases with a pathfinder
      cost penalty, and locks a freshly deployed conyard's expansion goal
      for a minimum hold time so it isn't immediately re-evaluated for a move.

    CNRepairManagerBotModule
      Sends damaged idle base units to repair — barracks-based infantry
      repair, RepairableNear vehicles, and mobile repair units (moves the
      damaged unit within the repairer's own auto-target range).

    CNBridgeRepairBotModule
      Assigns engineers/repair units to damaged bridge huts and requests
      replacement repairers via IBotRequestUnitProduction when none are
      available.

    CNCliffDemolitionBotModule
      Force-fires destroyable cliffs (see TERRAIN & MAP) open, but only where
      the opening buys something: inside a region the bot holds, or inside an
      enemy-held region it already has units in. Reads the sides a cliff
      separates off the region graph (CNTacticalMapBotModule) and skips any
      cliff with the same region on both sides. Prefers units not in a squad;
      squad units are only pulled in while idle.

  Combat Intelligence
  ~~~~~~~~~~~~~~~~~~~
    CombatAnalysisBotModule
      Weighted, decaying per-DefenseRole (InfantryDefense / ArmorDefense /
      AADefense / ArtilleryDefense / Special) threat tracker fed by
      incoming attacks. HasActiveThreat() / GetHighestThreatRole() drive
      both reactive base defense (CNBaseBuilderBotModule) and unit-builder
      panic checks. Also tracks a "nemesis" — the most persistent attacker —
      for allied-attack response.

    CNTacticalMapBotModule
      Cartographs the map once at game start (and on bridge changes):
      chokepoints (bridges, cliff ramps, narrow land passages) via the
      hierarchical pathfinder's abstract-graph cut-edges/articulation
      points, plus high-ground cliff edges overlooking the bot's own base.
      Feeds CNBaseBuilderBotModule's defense placement and chokepoint wall
      sealing, and (squad states) Raider/Stealth/Subterranean idle-state
      ambush repositioning. Incremental, chunked per-tick scans so multiple
      bots don't spike on the same tick. `cntopo` debug overlay.

  Squads
  ~~~~~~
    CNSquadManagerBotModule
      Template-based squad manager with slot-filling (carrier / passenger /
      escort roles), a weighted tag/need scoring model (TagWeights +
      NeedRules react to live enemy BotCapabilities) for template selection
      so production keeps cycling through every template instead of
      locking onto one "best" build, and a coordinated attack-wave system
      (squads hold near base until enough are ready, then march together to
      a staging rally point; EconomyOverflow shortens the wave interval and
      lowers the ready threshold when the bot has cash surplus). Nemesis-
      aware allied-attack response. Dedicated state machines per squad type:

        Ground (Idle/AttackMove/Attack/Flee)
          Composition-aware target scoring (SquadEngageFraction — prefers
          targets more of the squad can actually hit) and kill-securing on
          critically damaged enemies in easy reach before moving on.

        Artillery (Idle/HangBack/Bombard/Flee)
          Hangs back behind an attached assault squad; hang-back position
          is terrain-validated and prefers local high ground instead of a
          blind vector offset. Never dissolves on retreat — reforms and
          returns to idle.

        Raider / Stealth (Idle/Attack(or Approach)/Flee)
          Fuzzy attack-or-flee thresholds per profile. Repositions to a
          tactical-map chokepoint when no target is found instead of
          sitting still. Shared, optimized retreat-cell search (one threat
          scan for the whole candidate ring, not one per cell).

        Subterranean Assault / Transport (SUBTANK / SAPC)
          Deep-insertion burrow targeting at the value-weighted centroid of
          non-defense enemy buildings (surfaces in the economic core, not
          the defended perimeter). SAPC ambush-drops behind enemy lines.
          Travel timeouts use stuck-detection (reset on real positional
          progress) instead of a flat clock, so a squad crossing a large
          map isn't aborted for being slow rather than stuck.

        Aircraft (Attack/Raider/Return)
          Threat-scanned approach routing through gaps in AA coverage;
          composition-aware target scoring, same as Ground.

        Transport / AirTransport
          Capacity-aware multi-carrier passenger loading (stable, capacity-
          aware assignment map so trickle-in passengers don't all pile onto
          one carrier). Load timeout tracks actual boarding progress
          (Cargo.PassengerCount) and only aborts once boarding has
          genuinely stalled, not just because it's slow. Drops target the
          soft rear behind the wave's front rather than the defended edge.

        Support
          Follows an attached squad, heals/repairs (lowest-HP-then-cost
          priority); falls back to base-garrison duty when no squad to
          attach to.

        Protection
          Reactive squads that track and respond to multiple simultaneous
          attackers.

        Wave hold/rally
          Shared by every wave-eligible role. Going non-operational en
          route routes back through the squad's own role state machine
          (not a hardcoded ground flee) so Artillery/Subterranean squads
          persist and reform as designed instead of being force-dissolved.

    DeployBotModule
      Unified deploy/undeploy logic for all deployable unit types via
      configurable groups: Artillery (deploy in range, undeploy if the
      enemy closes past a safe range), Stats (deploy for a stat buff when
      idle with an enemy nearby), Support (deploy near enough allies,
      undeploy when alone or threatened), Ability (one-shot timed deploy
      for an ability duration).


ENGINE PATCHES  (CN fork — not in mainline OpenRA)
---------------------------------------------------
  Slope Speed System  [Locomotor.cs, Mobile.cs, Move.cs]
    Directional movement costs + smooth slopeSpeedFactor lerp per actor.
    EffectiveSlopeHeightDelta with ramp lookahead. GetSlopeSpeedFactor exposed
    from Locomotor; smoothed in Mobile.UpdateMovement() at 0.2 rate per tick.

  Aircraft Terrain Altitude Smoothing  [Aircraft.cs, Fly.cs]
    Aircraft.TerrainAltitudeSmoothing (WDist, opt-in per actor) does not
    exist in vanilla OpenRA. When set, Fly.FlyTick samples terrain height
    at 9 points spread along the aircraft's current movement direction
    (forward and behind, within the smoothing range) and averages them for
    the desired altitude, instead of snapping straight to the terrain
    height under the aircraft's exact current position. Smooths altitude
    changes over ramps/hills into a gradual glide. VoxelShadowSmoothing's
    own forward-sampling (see RENDERING & VOXELS) reuses this exact
    pattern for shadow ground height.

  OpenGL Depth / Alpha Fix  [OpenGL.cs, Sdl2GraphicsContext.cs]
    glBlendFuncSeparate (GL_ZERO, GL_ONE for alpha channel) +
    glDepthMask(false) for additive / subtractive blend modes. Prevents
    additive sprites from punching through opaque geometry.

  Multi-Cell Mobile  [SHELVED — not currently in the codebase]
    Was planned: multi-cell footprint support for mobile units, mirroring
    Building.cs pattern, local A* instead of HPA* pathfinding. Put on hold;
    may be revisited later. Nothing to carry through the bleed upgrade.

  TSMapGenerator Extensions  [TSMapGenerator.cs]
    Road split logic (SplitRoadRun): roads end cleanly before ramps with
    3-wide end-cap tiles instead of painting over slope tiles.
    Ramp guard (tileType > 0 check) prevents roads from overwriting ramps.

  Player Name Resolver Hook  [Player.cs, TraitsInterfaces.cs]
    New IResolvePlayerName interface (ResolvePlayerName(Player)); Player.cs
    queries every PlayerActor trait implementing it and uses the first
    non-null result as the display name. Doesn't exist in vanilla OpenRA —
    added purely so the mod-side BotPlayerNames trait (see UI & PLAYER)
    has somewhere to plug in.

  Label Strikethrough  [LabelWidget.cs]
    LabelWidgetInfo gained Strikethrough (bool) and IsStrikethroughVisible
    (Func<bool>) — draws a 1px horizontal line through the text when true.
    Generic widget-level support; not present in vanilla OpenRA. Consumed
    by GameInfoStatsLogic to strike through a defeated player's name in
    the player list (see UI & PLAYER: Defeated Player Strikethrough).

  Missile Enhancements  [Missile.cs, IJammableProjectile.cs]
    Three additions, none in vanilla OpenRA:
    (1) Second overlaid trail image (Trail2Image/Trail2Sequences/
    Trail2Palette/Trail2Interval/Trail2WhenDeactivated) so a missile can
    render two independent trail animations (e.g. smoke + fire) at once.
    (2) IJammableProjectile interface (IsJammable/SourceActor/GuidedTarget/
    Position), implemented by Missile — plumbing only, nothing currently
    reads it (no consumer in engine or mod yet).
    (3) Correctness fix: clamp h1 into [0, 2*loopRadius] in the homing
    inner-tick loop-geometry math so ISqrt is never fed a negative value
    when a slow/agile missile (small loopRadius) must climb more than a
    full loop diameter (e.g. a tall cliff).

  Named Handicap Tiers  [LobbyUtils.cs]
    Lobby's generic 0-95% handicap slider is replaced with Easy/Normal/Hard/
    Brutal for the cn mod only (gated on Game.ModData.Manifest.Id == "cn";
    other internal mods keep the vanilla % slider). Session.Client.Handicap
    holds a small tier index (0=Normal,1=Easy,2=Hard,3=Brutal), not a percent.

  Custom Graphics Settings Toggles  [Settings.cs]
    Seven fields added to GraphicSettings, none present in vanilla OpenRA:
    WaterEffects, PostProcessGrading (GradingMode: Off/Cinematic/ToxHaze),
    TiberiumEffects, CloudShadows, BloomGlowEffects, VoxelDynamics,
    ScreenShake. Exposed as the checkbox grid + Atmosphere dropdown in the
    Graphics settings screen. ScreenShake is the only one gating a vanilla
    trait (ScreenShaker.cs checks Game.Settings.Graphics.ScreenShake before
    applying scroll offset); the rest gate CN-only world traits — see
    RENDERING & VOXELS and WEATHER & ATMOSPHERE for what each one drives.

  Voxel Shadow Ground-Orientation Hook  [RenderVoxels.cs, ModelRenderable.cs]
    IRenderVoxelShadowModifier gained ShadowGroundOrientation alongside the
    existing ShadowGroundZ, threaded through ModelRenderable /
    FinalizedModelRenderable the same way. Previously the shadow's ground
    orientation was always sampled live per-frame from the actor's current
    cell with no smoothing, so hovering/flying voxels crossing a ramp cell
    boundary would see their shadow's projection matrix snap discontinuously.
    Falls back to the live per-cell lookup when no modifier overrides it.
    Consumed by the mod's VoxelShadowSmoothing trait (see RENDERING & VOXELS).
